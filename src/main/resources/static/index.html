🔁 Idempotency
Redis check → MySQL fallback → 24 hr TTL. The same idempotency key always returns the same transaction — never charged twice.
⏱ Exponential Backoff
RetryService polls every 5 s. Retry 1 → wait 2 s, Retry 2 → wait 4 s, Retry 3 → wait 8 s. Permanent FAILED after 3 failures.
🔒 Optimistic Locking
JPA @Version on every transaction row. Concurrent state updates throw an exception instead of silently corrupting data.
